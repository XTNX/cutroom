# Cutroom — план и статус

Десктоп-студия монтажа (Electron + FastAPI) поверх скилла video-use и ffmpeg. Все решения о нарезке принимает video-use по своим правилам; Cutroom показывает их, даёт править руками и запускает рендеры.

## Архитектура

```
Electron main (electron/main.cjs)
 ├─ окно (titleBarOverlay, запоминание размера), меню, диалоги, уведомления, powerSaveBlocker
 ├─ запускает backend: python -m cutroom.server --port <свободный> --token <случайный>
 │    и убивает дерево процессов (taskkill /T) при выходе; backend сам выходит, если умер родитель
 └─ preload.cjs — узкий мост: backend(), pickFolder/Files, pathForFile, reveal (только внутри проекта), setBusy, notify, onMenu
Renderer (src/, React + TS + Vite + Tailwind 4 + Zustand + Radix)
 └─ HTTP/WS к backend с токеном; прокси видео через HTTP Range
Backend (backend/cutroom, FastAPI)
 ├─ jobs.py     очередь: полосы io/audio/proxy/asr/pack/render со своим параллелизмом, DAG-зависимости, прогресс, ETA, отмена деревом
 ├─ project.py  папка проекта, edit/cutroom.db (SQLite), скан, дубликаты по содержимому, конвейер приёма
 ├─ media.py    ffprobe, прокси (NVENC/CPU, HLG→Rec.709, повороты), аудио 16 кГц, волна, быстрый хэш
 ├─ system.py   GPU/VRAM/RAM/CPU, ffmpeg и кодеры, модели, рекомендация, ETA часа аудио
 ├─ bench.py    замер ASR → edit/asr_benchmark.md
 ├─ sync.py     синхронизация ракурсов и петличек → edit/sync.json
 ├─ audio.py    микрофон по дублям (петличка — автоматически), цепочка обработки речи, пробник «до/после»
 ├─ music.py    музыкальная полка: анализ треков (темп, энергия), подбор к монтажу, список разрешённых библиотек
 ├─ helpers/render_cutroom.py  рендер: кадр с ракурса + звук с петлички, кадро-точные сегменты, PCM внутри, AAC один раз
 ├─ agent.py    вызовы Claude Code (-p, без инструментов, JSON-схема pydantic, данные в <data>)
 ├─ edl.py      ворота стратегии (хэш утверждённого текста), привязка к словам, версии EDL, раскрытие ракурсов для render.py
 ├─ stages.py   стратегия → редактор → EDL → фоновый render.py --preview
 └─ helpers/transcribe_whisper.py  локальный ASR (GigaAM / faster-whisper) → JSON в схеме Scribe (кэш по содержимому+модели+параметрам)
vendor/video-use  зафиксированный коммит 43cfc56; pack_transcripts.py, render.py, grade.py, timeline_view.py вызываются как есть
```

Все артефакты — в `<videos_dir>/edit/` (proxies/, audio16k/, waveforms/, thumbs/, transcripts/, cache/transcripts/, bench/, takes_packed.md, asr_benchmark.md, cutroom.db).

## Исправлено 2026-11-06
- Рендер падал на перемещённых исходниках (C1091 → «последние 2»): relink по имени+размеру, понятная ошибка вместо traceback.
- Перетаскивание нескольких файлов на таймлайн; ручные правки (камера, цвет, удаление) идут в выбранный эпизод, не к бегунку.
- Гонка SQLite: `edl.ensure_schema` делал executescript без блокировки на каждом чтении → «cannot commit - no transaction is active» у параллельных задач.
- Перерисовка одного слота дважды одновременно → WinError 32: каждая отрисовка в своей папке v<ts>, перерисовки слота идут по очереди.
- Eval: A/V считался по r_frame_rate (25), рендер — по avg (24.998): на границе .5 кадра расходились на кадр. Eval переведён на avg.
- Чужие edl.json / preview.mp4 бэкапятся один раз (edl.before-cutroom.json, preview.before-cutroom.mp4). Ручной edl.json в бф/2 был перезаписан до этого исправления; копия — бф/2/work/edl_prev.json.

## Известные ограничения

- Модель Whisper грузится заново на каждый файл (+4–10 с на файл). Постоянный воркер — в этап 9.
- Выравнивание WhisperX (wav2vec2) не подключено → паддинг стыков по умолчанию 100 мс.
- Диаризация не подключена (один спикер).
- Второе окно плеера открывается, но режим `?player=1` в рендерере ещё не реализован (этап 9).
- Если в дубле нет отдельной записи звука и микрофон не выбран, при смене ракурса звучит микрофон этой камеры.
- Обработка речи не слышна в живом превью — только в пробнике «до/после» и в рендере.
- Автопереключение ракурсов по спикеру не сделано (нет диаризации); переключение — вручную, в один клик на фрагменте.
